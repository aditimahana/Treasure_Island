# Treasure Island 🏴‍☠️💎

A text-based adventure game built as part of **Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp**.

The player makes a series of choices to navigate Treasure Island and try to find the hidden treasure. Choosing the wrong path results in a game over.

## What I Practiced

- Getting user input with `input()`
- Using `.lower()` to handle different capitalization
- `if`, `elif`, and `else` statements
- Nested conditional statements
- Comparing strings
- Creating branching game logic
- Using multiline strings with triple quotes
- Building a simple text-based game

## How It Works

The player is given a series of choices:

1. Choose whether to go **left** or **right** at a crossroads.
2. If they go left, choose whether to **wait** for a boat or **swim** across the lake.
3. If they wait, choose between **three doors**.
4. The correct choices lead to the treasure, while incorrect choices lead to different game-over outcomes.

## Goal

🏆 Find the treasure by making the correct choices!
